一、 USE 是干啥的？（一句话理解）
USE 就是“走进某个仓库”。想在某个数据库里建表、查数据，必须先用 USE 进入它，否则 MySQL 不知道你要操作哪个库。

二、 怎么进入数据库？（实操代码）

USE 数据库名;
-- 举例（进入 shlg 数据库）：
USE shlg;

三、 进去之后怎么确认自己没走错门？

-- 查看当前正在使用的数据库：
SELECT DATABASE();
-- 查看所有数据库（带 * 号的或高亮的就是当前所在的库）：
SHOW DATABASES;

**新手必踩大坑**：如果没有先 USE 任何数据库，直接建表会报错 “No database selected”。看到这个报错，第一反应就是补一句 USE。

四、 我的 Navicat 使用实记（2026-09-22 起，一直在 shlg 库操作）

我在 Navicat 查询编辑器里写过 SELECT DATABASE(); 确认自己当前在 shlg 库。

另外发现一个 Navicat 特性：它的查询编辑器会自动给表名补上 `shlg`.` 这种“库名.表名”全限定前缀（比如我写的每条语句都带 `shlg`.`emp1`），所以在 Navicat 里哪怕没写 USE 也不容易报 No database selected。但到了命令行/其他工具里就没这个待遇了，USE 还是要老老实实先写。
