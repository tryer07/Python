# 数据库进入备忘录

## 一、USE 是干啥的？（一句话理解）

USE 就是"走进某个仓库"。想在某个库里建表、查数据，必须先用 USE 进入它，否则 MySQL 不知道你在操作哪个库。

## 二、怎么进入数据库？

```sql
USE 数据库名;

-- 举例
USE shlg;
```

## 三、进去之后怎么确认没走错门？

```sql
SELECT DATABASE();   -- 查看当前正在使用的数据库
SHOW DATABASES;      -- 查看所有数据库
```

## 四、新手必踩大坑

没 USE 任何库就直接建表，会报 `No database selected`，看到就先补一句 USE。
