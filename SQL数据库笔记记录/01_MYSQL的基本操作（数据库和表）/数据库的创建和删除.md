一、 数据库是个啥？（一句话理解）
数据库就是存放数据的“大仓库”。一个 MySQL 服务里可以建很多个数据库，每个数据库里又能建很多张表。

二、 怎么创建数据库？（实操代码）

CREATE DATABASE 数据库名;
-- 推荐写法（防止报错，如果已存在就不创建）：
CREATE DATABASE IF NOT EXISTS 数据库名;
-- 举例：
CREATE DATABASE IF NOT EXISTS shlg;

三、 怎么查看和进入数据库？

-- 查看当前 MySQL 里所有的数据库：
SHOW DATABASES;
-- 查看当前正在使用哪个数据库：
SELECT DATABASE();
-- 进入（切换到）某个数据库，之后的操作都是在它里面进行的：
USE 数据库名;
-- 举例：
USE shlg;

四、 怎么删除数据库？（小心踩坑）

DROP DATABASE 数据库名;
-- 推荐写法（防止报错，如果不存在也不报错）：
DROP DATABASE IF EXISTS 数据库名;
-- 举例：
DROP DATABASE IF EXISTS shlg;

**新手必踩大坑**：DROP DATABASE 会把整个数据库连同里面所有的表和数据全部删掉，而且无法恢复！删之前一定确认自己 USE 的、要删的是哪个库，别手滑删错。
