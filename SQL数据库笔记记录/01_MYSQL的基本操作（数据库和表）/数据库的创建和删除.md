# 数据库的创建和删除

## 一、数据库是个啥？（一句话理解）

数据库就是存放数据的"大仓库"。一个 MySQL 服务里可以建很多个库，每个库里又能建很多张表。

## 二、怎么创建数据库？

```sql
CREATE DATABASE 数据库名;

-- 推荐写法：库已存在就不重复创建，不报错
CREATE DATABASE IF NOT EXISTS 数据库名;

-- 举例
CREATE DATABASE IF NOT EXISTS shlg;
```

## 三、怎么查看和进入数据库？

```sql
SHOW DATABASES;      -- 查看所有数据库
SELECT DATABASE();   -- 查看当前在用哪个库
USE 数据库名;        -- 进入某个库，之后的操作都在它里面
USE shlg;
```

## 四、怎么删除数据库？

```sql
DROP DATABASE 数据库名;

-- 推荐写法：库不存在也不报错
DROP DATABASE IF EXISTS 数据库名;

DROP DATABASE IF EXISTS shlg;
```

## 五、新手必踩大坑

- DROP DATABASE 会把库里所有的表和数据全部删掉，无法恢复，删之前确认清楚是哪个库。
- 库已经存在时再 CREATE 会报 `Can't create database 'xxx'; database exists`，所以建库永远带上 `IF NOT EXISTS`。
