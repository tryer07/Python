一、 数据库是个啥？（一句话理解）
数据库就是存放数据的“大仓库”。一个 MySQL 服务里可以建很多个数据库，每个数据库里又能建很多张表。

二、 怎么创建数据库？（实操代码）

CREATE DATABASE 数据库名;
-- 推荐写法（防止报错，如果已存在就不创建）：
CREATE DATABASE IF NOT EXISTS 数据库名;
-- 举例：
CREATE DATABASE IF NOT EXISTS shlg;

三、 怎么查看和进入数据库？

-- 查看当前 MySQL 里所有的数据库：
SHOW DATABASES;
-- 查看当前正在使用哪个数据库：
SELECT DATABASE();
-- 进入（切换到）某个数据库，之后的操作都是在它里面进行的：
USE 数据库名;
-- 举例：
USE shlg;

四、 怎么删除数据库？（小心踩坑）

DROP DATABASE 数据库名;
-- 推荐写法（防止报错，如果不存在也不报错）：
DROP DATABASE IF EXISTS 数据库名;
-- 举例：
DROP DATABASE IF EXISTS shlg;

五、 我的 Navicat 真实操作实录（2026-09-22）

我当天建了 test 和 test1 两个测试库，实际执行的语句是：

CREATE DATABASE `test1` CHARACTER SET 'utf8';  -- 建库时直接指定 utf8 字符集
DROP DATABASE `test1`;                          -- 试完就删（当时没加 IF EXISTS）

-- 建库时带上 CHARACTER SET 'utf8'，该库的默认排序规则就是 utf8_general_ci，
-- 以后库里建的表不单独指定的话，也继承这个字符集。

**新手必踩大坑**：DROP DATABASE 会把整个数据库连同里面所有的表和数据全部删掉，而且无法恢复！删之前一定确认自己 USE 的、要删的是哪个库，别手滑删错。

**我自己踩过的坑**：9 月 22 日 17:24，我执行 CREATE DATABASE `test` CHARACTER SET 'utf8'，当场报错：
Can't create database 'test'; database exists
库已经存在了还想再建一遍，MySQL 直接拒绝。这条报错就是 IF NOT EXISTS 存在的意义——养成习惯，建库语句永远带上它。
