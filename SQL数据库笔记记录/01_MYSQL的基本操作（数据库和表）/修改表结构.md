# 修改表结构

## 一、修改表结构用啥？（一句话理解）

表建好之后想改名、改字段、加列删列，统统用 ALTER TABLE 这一个命令家族搞定。

## 二、怎么修改表名？

```sql
-- 写法一
ALTER TABLE 旧表名 RENAME TO 新表名;
ALTER TABLE employees RENAME TO emp;

-- 写法二（等价，还能一次改多张表）
RENAME TABLE 旧表名 TO 新表名;
RENAME TABLE employees TO employees1;
```

## 三、怎么修改列名？（两种写法）

```sql
-- 方法一：CHANGE（老写法，必须带上原数据类型）
ALTER TABLE 表名 CHANGE COLUMN 旧列名 新列名 数据类型;

-- 方法二：RENAME COLUMN（MySQL 8.0 推荐，不用带类型）
ALTER TABLE 表名 RENAME COLUMN 旧列名 TO 新列名;

ALTER TABLE emp RENAME COLUMN employee_name TO emp_name;
```

## 四、怎么修改列？

```sql
-- 改类型
ALTER TABLE 表名 MODIFY COLUMN 列名 新数据类型;
ALTER TABLE emp MODIFY COLUMN salary DECIMAL(10,2);

-- MODIFY 是整列重建，除了类型还能改这些：
ALTER TABLE 表名 MODIFY COLUMN 列名 类型 NOT NULL;                -- 加非空
ALTER TABLE 表名 MODIFY COLUMN 列名 类型 NOT NULL AUTO_INCREMENT;  -- 加自增
ALTER TABLE 表名 MODIFY COLUMN 列名 类型 FIRST;                   -- 移到最前面
ALTER TABLE 表名 MODIFY COLUMN 列名 类型 AFTER 另一列;            -- 移到某列后面
```

注意：MODIFY 要把这一列的最终完整定义（类型 + NULL 属性 + 位置）一次写全，漏写会被恢复成默认值。

## 五、怎么添加新列？

```sql
ALTER TABLE 表名 ADD COLUMN 新列名 数据类型;
ALTER TABLE emp ADD COLUMN age INT;                -- 默认加在最后
ALTER TABLE emp ADD COLUMN gender CHAR(1) AFTER emp_name;  -- 指定位置
```

## 六、怎么删除指定列？

```sql
ALTER TABLE 表名 DROP COLUMN 列名;
ALTER TABLE emp DROP COLUMN age;
```

## 七、新手必踩大坑

- DROP COLUMN 会把这一列的数据全删掉，无法恢复。
- MODIFY 把类型改"小"（如 VARCHAR(20) 改 VARCHAR(5)）时，已有数据可能被截断，改前先确认数据。
