# 表的创建和删除

## 一、表是个啥？（一句话理解）

表就是库里的"Excel 表格"，由行（一条记录）和列（一个字段）组成。建表时要说清楚：表名、有哪些字段、每个字段什么类型。

## 二、怎么创建表？

```sql
CREATE TABLE 表名 (
    字段名1 数据类型,
    字段名2 数据类型
);

-- 举例（最后一个字段后面没有逗号）
CREATE TABLE employees (
    employee_id INT,
    employee_name VARCHAR(10),
    salary DECIMAL(8,2)
);
```

建表前必须先 USE 进入某个库。

## 三、建完怎么检查？

```sql
SHOW TABLES;    -- 查看库里所有的表
DESC 表名;      -- 查看表结构

DESC employees;
```

## 四、怎么删除表？

```sql
DROP TABLE 表名;

-- 推荐写法：表不存在也不报错
DROP TABLE IF EXISTS 表名;

DROP TABLE IF EXISTS employees;
```

## 五、新手必踩大坑

- DROP TABLE 把表结构和数据一起删掉，无法恢复。只想清数据留表结构的话，用 `TRUNCATE TABLE 表名;`
- 没 USE 库就建表，报 `No database selected`。

## 六、我的 Navicat 真实操作实录（2026-09-22，shlg 库）

```sql
-- 生效：建表失败，employee_id 想当主键却允许了 NULL，MySQL 直接拒绝
CREATE TABLE `shlg`.`employee2` (
    `employee_id` int NULL,
    `employee_name` varchar(10) NULL,
    `salary` float(8, 2) NULL,
    PRIMARY KEY (`employee_id`)
);
-- 报错：All parts of a PRIMARY KEY must be NOT NULL; if you need NULL in a key, use UNIQUE instead

-- 生效：建表成功，shlg 库多出 employee2 表，三个字段均 NOT NULL，employee_id 为主键
CREATE TABLE `shlg`.`employee2` (
    `employee_id` int NOT NULL,
    `employee_name` varchar(10) NOT NULL,
    `salary` float(8, 2) NOT NULL,
    PRIMARY KEY (`employee_id`)
);

-- 生效：列出 employee2 的字段明细（类型、是否可空、字符集等），确认刚建的表结构无误
SHOW FULL COLUMNS FROM `employee2`;

-- 生效：employee2 改名为 employees2（数据不变，只是换了个表名）
RENAME TABLE `shlg`.`employee2` TO `shlg`.`employees2`;

-- 生效：employees2 表连同数据被删除，shlg 库里不再有这个表
DROP TABLE IF EXISTS `shlg`.`employees2`;
```
