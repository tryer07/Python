一、 表是个啥？（一句话理解）
表就是数据库里的“Excel 表格”，由行（一条记录）和列（一个字段）组成。建表时必须先说清楚：表叫什么名字、有哪些字段、每个字段存什么类型的数据。

二、 怎么创建表？（实操代码）

CREATE TABLE 表名 (
    字段名1 数据类型,
    字段名2 数据类型,
    字段名3 数据类型
);
-- 举例（注意最后一个字段后面没有逗号）：
CREATE TABLE employees (
    employee_id INT,
    employee_name VARCHAR(10),
    salary DECIMAL(8,2)
);

三、 建完之后怎么检查？

-- 查看当前数据库里所有的表：
SHOW TABLES;
-- 查看某张表的结构（有哪些字段、什么类型）：
DESC 表名;
-- 举例：
DESC employees;

四、 怎么删除表？（小心踩坑）

DROP TABLE 表名;
-- 推荐写法（防止报错，如果不存在也不报错）：
DROP TABLE IF EXISTS 表名;
-- 举例：
DROP TABLE IF EXISTS employees;

**新手必踩大坑**：DROP TABLE 会把表结构和里面的数据一起删掉，无法恢复！如果只想清空数据、保留表结构，应该用 TRUNCATE TABLE 表名;

**另一个小坑**：建表前必须先 USE 进入某个数据库，否则报错 “No database selected”。

五、 我的 Navicat 真实操作实录（2026-09-22）

1. 我在 shlg 库里实际建过一张 employee2 表，工资列用的是 FLOAT(8,2)：

CREATE TABLE `shlg`.`employee2` (
    `employee_id` int NOT NULL,
    `employee_name` varchar(10) NOT NULL,
    `salary` float(8, 2) NOT NULL,           -- 我实际用的是 FLOAT(8,2)，和例子里的 DECIMAL(8,2) 不同
    PRIMARY KEY (`employee_id`)
);
-- 注意：Navicat 查询编辑器会自动给表名补上 `shlg`.` 前缀（全限定），所以即使没 USE 也不会报 No database selected；但命令行里还是要先 USE。

2. 建完我检查字段用的是：

SHOW FULL COLUMNS FROM `employee2`;  -- 比 DESC 看得更全，能把字符集、注释一并看出来（Navicat 刷新表结构时背后发的就是这句）

3. 改名和删除也都是我真实执行过的：

RENAME TABLE `shlg`.`employee2` TO `shlg`.`employees2`;  -- 改名（写法见《修改表结构》笔记）
DROP TABLE IF EXISTS `shlg`.`employees2`;                -- 试完就删，IF EXISTS 养成习惯

**我自己踩过的坑**：第一版 employee2 我把三个字段都建成了 NULL，还想拿 employee_id 当主键，当场报错：
All parts of a PRIMARY KEY must be NOT NULL; if you need NULL in a key, use UNIQUE instead
主键列必须 NOT NULL，第二版改成 NOT NULL 才建成功。详细原理见《主键约束》笔记。
