表的创建和删除

表的创建：

CREATE TABLE 表名 (
    字段名1 数据类型,
    字段名2 数据类型,
    字段名3 数据类型
);
-- 举例（注意最后一个字段后面没有逗号）：
CREATE TABLE employees(
    employee_id int,
    employee_name varchar(10),
    salary decimal(8,2)
);

查看当前数据库所有的表：

SHOW TABLES;

查看表结构：

DESC 表名;

删除表：

DROP TABLE 表名;
-- 推荐写法：
DROP TABLE IF EXISTS 表名;
-- 举例：
DROP TABLE IF EXISTS employees;
