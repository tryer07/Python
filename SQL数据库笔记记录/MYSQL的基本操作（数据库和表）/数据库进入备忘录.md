一、 USE 是干啥的？（一句话理解）
USE 就是“走进某个仓库”。想在某个数据库里建表、查数据，必须先用 USE 进入它，否则 MySQL 不知道你要操作哪个库。

二、 怎么进入数据库？（实操代码）

USE 数据库名;
-- 举例（进入 shlg 数据库）：
USE shlg;

三、 进去之后怎么确认自己没走错门？

-- 查看当前正在使用的数据库：
SELECT DATABASE();
-- 查看所有数据库（带 * 号的或高亮的就是当前所在的库）：
SHOW DATABASES;

**新手必踩大坑**：如果没有先 USE 任何数据库，直接建表会报错 “No database selected”。看到这个报错，第一反应就是补一句 USE。
