# 向表中插入数据（INSERT）

## 一、插入数据是干啥？（一句话理解）

INSERT 就是往表里"添加一行新记录"。可以只给部分列填值（指定列插入），也可以按列的顺序把所有列都写一遍（完全插入）。

## 二、两种基本写法（实操代码）

```sql
-- 写法一：指定列插入（只写要填的列，没写的列走默认/自增）
INSERT INTO department (department_name, location_id)
VALUES ('market', 1);

-- 写法二：完全插入（不写列名，值的顺序必须和表的列顺序一一对应）
INSERT INTO department
VALUES (DEFAULT, 'development', 2);
```

## 三、自增主键怎么占位？（本节课重点）

主键带了 AUTO_INCREMENT 时，插入这行你还不知道编号该填几，可以让 MySQL 自动分配。占位方式有三种都管用：

```sql
INSERT INTO department VALUES (DEFAULT, 'development', 2);  -- 用 DEFAULT
INSERT INTO department VALUES (NULL,     'human',     3);   -- 用 NULL
INSERT INTO department VALUES (0,        'teaching',  4);   -- 用 0
```

- **不能用空字符串 `''`** 去占自增主键的位，会报错。

## 四、字段长度不够怎么办？

插入的字符串比列定义的长度长时，会报 `Data too long for column ...`，先把列改长再插：

```sql
-- 把 department_name 从 VARCHAR(10) 放宽到 VARCHAR(20)
ALTER TABLE department MODIFY department_name VARCHAR(20);
```

## 五、新手必踩大坑

- 完全插入不写列名，值的个数和顺序必须跟表结构完全对齐，少一个/错一位就报错或串列。
- 自增主键占位只能用 `DEFAULT`、`NULL`、`0`，用 `''`（空字符串）不行。
- 插入前如果列长度可能不够，先确认字段定义，撞上报错再 `MODIFY` 改长。

## 六、在 Navicat 里的操作流程

1. 连接后双击进入库，找到目标表（如 `departments`）
2. 点 **查询 → 新建查询**，把 INSERT 语句粘进去执行
3. 执行完回左侧表列表**右键刷新**，或双击打开表看新加的行有没有进去

## 七、我的 Navicat 真实操作实录（2026-10-21 晚，表实际名为 departments）

```sql
-- 19:50 把字段先收窄到 VARCHAR(10)，为的是等下故意触发报错
ALTER TABLE departments MODIFY department_name VARCHAR(10);

-- 19:50 指定列插入（'market' 长度够，成功）
INSERT INTO departments (department_name, location_id) VALUES ('market', 1);
-- 生效：只填了名称和位置两列，department_id 由自增自动补上

-- 19:51 完全插入用 DEFAULT 占位（此时长度还是 10，'development' 有 11 个字符，塞不下）
INSERT INTO departments VALUES (DEFAULT, 'development', 2);
-- 报错：Data too long for column 'department_name' at row 1

-- 19:51 把长度放宽到 VARCHAR(20)
ALTER TABLE departments MODIFY department_name VARCHAR(20);
-- 生效：department_name 变长到 20，装得下 development 了

-- 重新完全插入，成功
INSERT INTO departments VALUES (DEFAULT, 'development', 2);
-- 生效：department_id 用 DEFAULT 占位，自增自动分配了下一个编号

-- NULL 占位插入
INSERT INTO departments VALUES (NULL, 'human', 3);
-- 生效：自增主键位置填 NULL，MySQL 同样自动分配编号

-- 0 占位插入
INSERT INTO departments VALUES (0, 'teaching', 4);
-- 生效：自增主键位置填 0，也触发了自动分配编号

-- 19:55 试完把这几行删掉
DELETE FROM `shlg`.`departments` WHERE `department_id` = 3;
DELETE FROM `shlg`.`departments` WHERE `department_id` = 4;
DELETE FROM `shlg`.`departments` WHERE `department_id` = 5;
DELETE FROM `shlg`.`departments` WHERE `department_id` = 6;
```
