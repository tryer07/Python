一、 主键是个啥？（一句话理解）
主键就是一张表里的“身份证号”。它的作用就是唯一标识表里的某一行数据。

二、 主键的“三大铁律”（一定要背下来）
不能重复：比如学生表，学号是主键，那就不能有两个学号一样的学生。

不能为空（NULL）：必须有值，不能空着。

一张表只能有一个主键（但可以是由多个字段组合成的“复合主键”）。

三、 怎么加主键？（实操代码）
1. 建表的时候顺手加上（推荐，最常用）

单列主键（最常用）：

CREATE TABLE emp (
    id INT PRIMARY KEY,  -- 直接跟在字段后面
    name VARCHAR(20)
);

复合主键（多列一起做主键）：

CREATE TABLE student_course (
    stu_id INT,
    course_id INT,
    score FLOAT,
    PRIMARY KEY (stu_id, course_id)  -- 写在最后，两列一起做主键
);
2. 表已经建好了，想补加主键（用 ALTER）：

ALTER TABLE emp ADD PRIMARY KEY (id);

四、 怎么删主键？（小心踩坑）

ALTER TABLE emp DROP PRIMARY KEY;

 新手必踩大坑：如果你的主键带了 AUTO_INCREMENT（自增），直接删主键会报错！必须先用 ALTER TABLE emp MODIFY id INT; 把自增属性去掉，然后再删主键。
