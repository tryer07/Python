# 主键约束

## 一、主键是个啥？（一句话理解）

主键就是表里的"身份证号"，用来唯一标识某一行数据。

## 二、主键的三大铁律

1. 不能重复
2. 不能为空（NULL）
3. 一张表只能有一个主键（可以是多列组合的复合主键）

## 三、怎么加主键？

```sql
-- 单列主键（建表时直接跟在字段后面）
CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(20)
);

-- 复合主键（写在最后，两列一起做主键）
CREATE TABLE student_course (
    stu_id INT,
    course_id INT,
    score FLOAT,
    PRIMARY KEY (stu_id, course_id)
);

-- 表建好了再补加
ALTER TABLE emp ADD PRIMARY KEY (id);
```

## 四、怎么删主键？

```sql
ALTER TABLE emp DROP PRIMARY KEY;
```

## 五、新手必踩大坑

- 主键带了 AUTO_INCREMENT 时直接删主键会报错，必须先用 `MODIFY id INT` 去掉自增，再删主键。
- 补主键前这一列必须没有 NULL 且数据不重复，否则 MySQL 拒绝。

## 六、我的 Navicat 真实操作实录（shlg 库）

```sql
-- 2026-09-22 建 employee2 表（失败）
-- 生效：建表被拒绝，因为主键列 employee_id 允许了 NULL，违反主键“不能为空”铁律
CREATE TABLE `shlg`.`employee2` (
    `employee_id` int NULL,
    `employee_name` varchar(10) NULL,
    `salary` float(8, 2) NULL,
    PRIMARY KEY (`employee_id`)
);
-- 报错：All parts of a PRIMARY KEY must be NOT NULL; if you need NULL in a key, use UNIQUE instead

-- 2026-09-22 第二版（成功）
-- 生效：建表成功，employee_id 为 NOT NULL 且是主键，每行靠它唯一区分
CREATE TABLE `shlg`.`employee2` (
    `employee_id` int NOT NULL,
    `employee_name` varchar(10) NOT NULL,
    `salary` float(8, 2) NOT NULL,
    PRIMARY KEY (`employee_id`)
);

-- 2026-09-28 19:31 给 emp1 补主键
-- 生效：同一条 ALTER 里 employee_id 加了自增，并正式成为 emp1 的主键
ALTER TABLE `shlg`.`emp1`
    MODIFY COLUMN `employee_id` int(11) NOT NULL AUTO_INCREMENT FIRST,
    ADD PRIMARY KEY (`employee_id`);

-- 2026-09-28 19:32 删主键
-- 生效：先把自增去掉、再删主键，employee_id 变回普通 int NOT NULL 列（顺序反了会报错）
ALTER TABLE `shlg`.`emp1`
    MODIFY COLUMN `employee_id` int(11) NOT NULL FIRST,
    DROP PRIMARY KEY;
```
