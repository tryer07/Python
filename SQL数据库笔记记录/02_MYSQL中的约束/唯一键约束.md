# 唯一键约束

## 一、唯一键是个啥？（一句话理解）

唯一键就是"不许撞车的名字"，保证某一列（或几列）的值在整张表里不能重复。它和主键很像，但更宽松：主键一张表只能有一个且不能为空，唯一键可以有多个、还能容纳 NULL。

## 二、唯一键的三大铁律

1. 值不能重复（重复了就报 Duplicate entry）
2. 允许为 NULL，而且可以有多个 NULL（这点和主键不一样）
3. 一张表可以有多个唯一键

## 三、怎么加唯一键？

```sql
-- 建表时直接跟在字段后面
CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(20) UNIQUE
);

-- 建表时在最后单独声明（可以起名字）
CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(20),
    UNIQUE uk_name (name)
);

-- 表建好了再补加
ALTER TABLE emp ADD UNIQUE uk_name (name);
```

## 四、怎么删唯一键？

```sql
-- 唯一键本质是一个“唯一索引”，删除用 DROP INDEX + 索引名
ALTER TABLE emp DROP INDEX uk_name;
```

## 五、新手必踩大坑

- 删唯一键要用 `DROP INDEX 索引名`，不是 `DROP FOREIGN KEY`，也不是写列名。
- 加唯一键前这一列不能已经有重复值（NULL 可以有多个不受限），否则 MySQL 拒绝。
- 需要"可以为空、但不能重复"时用唯一键，别用主键（主键不许 NULL）。

## 六、我的 Navicat 真实操作实录（2026-10-21，shlg.emp1 表）

```sql
-- 2026-10-21 10:50 加唯一键
-- 生效：emp_name 列加上唯一约束（索引名 emp1_uk），此后插入重复的 emp_name 会被拒绝；当时 4 行名字都不重复，所以加成功
ALTER TABLE `shlg`.`emp1`
    ADD UNIQUE INDEX `emp1_uk`(`emp_name`);

-- 2026-10-21 10:51 删唯一键
-- 生效：emp1_uk 唯一索引被删除，emp_name 恢复成可以重复填
ALTER TABLE `shlg`.`emp1`
    DROP INDEX `emp1_uk`;
```
