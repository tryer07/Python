# 非空约束

## 一、非空约束是个啥？（一句话理解）

非空约束（NOT NULL）就是"这一列必须填，不许留空"。加了它之后，插入或更新时这列不给值（NULL）就会被拒绝。

## 二、非空约束的三大铁律

1. 这列不能是 NULL，必须有值
2. 空字符串 `''`、数字 `0` 都不算 NULL，是可以填进去的
3. 主键天生自带 NOT NULL，不用你再额外加

## 三、怎么加非空约束？

```sql
-- 建表时直接跟在类型后面
CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(20) NOT NULL
);

-- 表建好了再补：用 MODIFY 重写这一列（要把类型一并写全）
ALTER TABLE emp MODIFY COLUMN name VARCHAR(20) NOT NULL;
```

## 四、怎么去掉非空约束？

```sql
-- 同样是 MODIFY，把 NOT NULL 换成 NULL 即可
ALTER TABLE emp MODIFY COLUMN name VARCHAR(20) NULL;
```

## 五、新手必踩大坑

- 非空约束没有独立的约束名，只能靠 `MODIFY COLUMN` 来加或去，不能用 `DROP CONSTRAINT`。
- 给一张已有数据的列补 NOT NULL 前，得先把里面已有的 NULL 值填上，否则 MySQL 会拒绝或把空值变成默认值。
- MODIFY 是整列重建，去/加 NOT NULL 时要把类型、字符集、位置一起写全，漏了会被重置成默认。

## 六、我的 Navicat 真实操作实录（2026-10-21，shlg.emp1 表）

```sql
-- 2026-10-21 10:58 把 salary 放开成允许空
-- 生效：salary 从 NOT NULL 改回 NULL，之后插入可以不给工资（该列留空）
ALTER TABLE `shlg`.`emp1`
    MODIFY COLUMN `salary` float(8, 2) NULL AFTER `emp_name`;

-- 2026-10-21 11:00 又把 salary 收紧成非空
-- 生效：salary 重新变回 NOT NULL，之后插入若不给 salary 就报错；当时各行 salary 都有值，所以改成功
ALTER TABLE `shlg`.`emp1`
    MODIFY COLUMN `salary` float(8, 2) NOT NULL AFTER `emp_name`;
```
