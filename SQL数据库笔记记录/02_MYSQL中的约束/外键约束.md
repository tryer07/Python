一、 外键是个啥？（一句话理解）
外键就是一张表里的“牵线绳”。它把两张表关联起来，保证你填进去的关联数据是真实存在的，不能瞎写。
比如：员工表 emp 里有个 dept_id（部门编号），它就是外键，指向部门表 dept 的主键 id。意思是“这个员工必须属于某个真实存在的部门”。

二、 外键的“三大铁律”（一定要背下来）
被引用的那一列，必须是另一张表的主键（或唯一键）：不然牵线牵到空气上。

外键列和被引用列的数据类型要一致：比如都是 INT，不能一个 INT 一个 VARCHAR。

外键的值必须是父表里已有的值，或者为 NULL：你不能填一个部门表里根本不存在的 dept_id。
（父表=被引用的表，子表=有外键的表）

三、 怎么加外键？（实操代码）
1. 建表的时候顺手加上（推荐，最常用）

CREATE TABLE dept (
    id INT PRIMARY KEY,          -- 父表：被引用的主键
    dept_name VARCHAR(20)
);

CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(20),
    dept_id INT,                 -- 子表：这一列要做外键
    FOREIGN KEY (dept_id) REFERENCES dept (id)  -- 指向 dept 表的 id 列
);

2. 表已经建好了，想补加外键（用 ALTER）：

ALTER TABLE emp ADD FOREIGN KEY (dept_id) REFERENCES dept (id);
-- 进阶：给外键起个名字（方便以后删除），并设置级联规则
ALTER TABLE emp ADD CONSTRAINT fk_emp_dept FOREIGN KEY (dept_id)
    REFERENCES dept (id)
    ON DELETE CASCADE       -- 父表记录被删时，子表相关记录跟着一起删
    ON UPDATE CASCADE;      -- 父表主键被改时，子表外键跟着一起改

四、 怎么删外键？（小心踩坑）

-- 删除外键需要知道它的“约束名”
ALTER TABLE emp DROP FOREIGN KEY fk_emp_dept;
-- 如果建表时没起名字，MySQL 会自动生成一个（比如 emp_ibfk_1），
-- 可以用下面的语句查出约束名再删：
SHOW CREATE TABLE emp;

 新手必踩大坑：
1. 删外键必须用约束名，不是列名！写成 DROP FOREIGN KEY (dept_id) 会报错，正确写法是 DROP FOREIGN KEY 约束名（不带括号）。
2. 建外键时报错 “Cannot add foreign key constraint”，八成是这几种原因：两张表引擎不是 InnoDB、数据类型不一致、或者被引用的那一列不是主键/唯一键。
3. 想删父表时，如果子表还有数据引用它，会删不掉报错。要么先删子表数据，要么建外键时就设好 ON DELETE CASCADE 级联删除。
