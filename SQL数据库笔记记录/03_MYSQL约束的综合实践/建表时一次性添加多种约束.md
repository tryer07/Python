# 建表时一次性添加多种约束

## 一、这节课干啥？（一句话理解）

把前面学的主键、自增、唯一、非空全串起来，在 `CREATE TABLE` 一行语句里给不同列各挂上合适的约束，建出一张"规则齐全"的表。

## 二、综合示例（实操代码）

以这节课的 depts 表为例：

```sql
CREATE TABLE depts (
    department_id   INT PRIMARY KEY AUTO_INCREMENT,  -- 主键 + 自增：不用手填，自动 +1
    department_name VARCHAR(30) UNIQUE,              -- 唯一：部门名不能重复
    location_id     INT NOT NULL                     -- 非空：位置编号必须填
);
```

三个约束分别落在三列上，各司其职：
- department_id：主键约束 + 自动增长
- department_name：唯一约束
- location_id：非空约束

## 三、建完先验证

```sql
SHOW KEYS FROM depts;          -- 看主键 PRIMARY、唯一键在不在
DESC depts;                    -- 看 location_id 的 Null 列是不是 NO
```

## 四、新手必踩大坑

- **语法空格/换行**：`location_id INT NOT NULL` 里每个词之间都要有空格，写成 `location_id INTNOT NULL` 或漏了分隔会报语法错误（我这节课就特意被提醒过这点）。
- **AUTO_INCREMENT 必须配索引**：自增列得同时是主键（或唯一键），单写 `INT AUTO_INCREMENT` 不给主键会报错。
- 最后一个字段后面**别再补逗号**，否则报语法错。

## 五、在 Navicat 里的完整操作流程

1. 新建查询窗口，把 `CREATE TABLE depts (...)` 粘进去执行
2. 执行完在左侧表列表**右键刷新**，看到 depts 表出现
3. 右键 depts 表 → **设计表 / 表信息**，界面上能看到建表时加的约束都生效了（主键有钥匙图标、非空列勾掉了“允许 NULL”）

## 六、我的 Navicat 真实操作实录

> 上面第二节的 `department_id / AUTO_INCREMENT / UNIQUE` 是课本的“三约束齐全版”；我在 Navicat 里实际跑的是下面这个**简化版**，只有主键 + 非空两个约束。

```sql
-- 2026-10-21 19:43 建 depts 表（实际版本）
-- 生效：depts 建成，deptno 是主键、dname 非空、loc 无约束（这版没有自增，也没唯一）
CREATE TABLE depts (
    deptno INT PRIMARY KEY,        -- 部门编号，设为主键
    dname VARCHAR(50) NOT NULL,    -- 部门名称，不能为空
    loc VARCHAR(50)                -- 部门所在地
);

-- 2026-10-21 19:43 建完先看结构
-- 生效：dname 的 Null 列为 NO（非空生效），loc 的 Null 列为 YES
SHOW FULL COLUMNS FROM `depts`;

-- 2026-10-21 19:44 再查约束
-- 生效：Key_name 里出现 PRIMARY（deptno）；非空不会出现在这里
SHOW KEYS FROM depts;
```
