# 查看表中的约束信息

## 一、为什么要查看约束？（一句话理解）

一张表建完后，里面有哪些主键、唯一键、外键、非空，用 `SHOW KEYS` 等命令就能一次性看清楚，不用靠猜。

## 二、怎么查看？（实操代码）

```sql
SHOW KEYS FROM 表名;      -- 列出表上所有的键（索引）

SHOW KEYS FROM depts;
```

## 三、结果怎么看？（重点看 Key_name 这一列）

| Key_name | 是什么约束 | 对应列的特征 |
|---|---|---|
| PRIMARY | 主键 | 唯一且非空，一表只有一个 |
| 唯一键的索引名（如 department_name） | 唯一约束 | Non_unique = 0，可以有 NULL |
| 外键会自动创建一个同名索引 | 外键约束 | 指向父表 |

- Non_unique = 0：这一列不允许重复（主键、唯一键都是 0）
- Non_unique = 1：允许重复
- 注意：`SHOW KEYS` 主要看"键类"约束（主键/唯一/外键），**非空 NOT NULL 不在这里显示**，要看 `DESC 表名` 或 `SHOW FULL COLUMNS` 里 `Null` 那一列。

## 四、新手必踩大坑

- 外键虽然是个约束，但删它要用 `DROP FOREIGN KEY 约束名`，而 `SHOW KEYS` 里看到的那条是它自带的索引；删索引 ≠ 删外键，别搞混。
- 想在界面里看得更全（含非空、默认值、字符集），用 `SHOW FULL COLUMNS FROM 表名;` 或 Navicat 的"设计表"。

## 五、我的 Navicat 真实操作实录（2026-10-21 晚）

```sql
-- 2026-10-21 19:40 查看两张已有表的约束
-- 生效：返回 emp1 当前的键列表，用来确认它有哪些主键/唯一/外键索引
SHOW KEYS FROM emp1;
-- 生效：返回 departments 的键，Key_name 里有 PRIMARY（主键 department_id）
SHOW KEYS FROM departments;

-- 2026-10-21 19:44 查看刚建的 depts 表的约束
-- 生效：Key_name 里出现 PRIMARY（deptno 主键）；dname 的非空不显示在这里，要靠 SHOW FULL COLUMNS 看
SHOW KEYS FROM depts;
```
